# 이 레포의 작업 규칙

## 0. 원본 보존
- inputs/ 아래 파일은 읽기만 한다. 고치거나 지우지 않는다.
- 결과는 outputs/m{모듈 번호}/ 에 새 파일로 만든다.
- 커밋 메시지는 사용자가 정한 머리([M1] 등)를 쓴다.

## 1. 근거 규칙
모든 수치·결정·기한에 [값 | 출처 파일 | 위치(발언 순번·행) | 처리]를 붙인다. 정정 발언은 정정 후 값을 쓴다. 잡담·개인정보는 회의록에서 뺀다. 자료에 없으면 {확인 필요: 항목}. 근거표는 원문 위치를 다시 열어 대조한 뒤 확정한다. 개인정보에는 이름이 없어도 동·호수와 연락처 일부를 포함한다.

## 2. 집계 기준
원본 CSV는 수정하지 않는다. 계산은 말로 하지 않고 scripts/로 실행한다. 중복·단위·합계 행·비표준 표기의 처리 기준은 rules/aggregation_rules.md를 따르고, 제외한 행은 사유와 함께 excluded_rows.csv에 남긴다. 결과는 검산표·두 번째 방법으로 대조한 뒤 확정한다. 신청방법은 콜센터·온라인·방문 3종으로 집계한다. 다른 표기는 rules/aggregation_rules.md의 대응표로 정규화하고 수정 행으로 기록한다. 대응표에 없는 표기는 '신청방법 확인 필요'로 제외하고 담당자에게 묻는다.

## 3. 정합 규칙
수치는 ledger/ledger.csv가 단일 기준이다. 문서 수정은 지정한 항목만 바꾸고 나머지 문장은 그대로 둔다. 대장이 바뀌면 먼저 영향 문서 목록(impact_list)을 만들고, 승인 후 연결 문서를 한꺼번에 고친다. 고친 뒤 consistency_check로 불일치 0건을 확인하고 변경 사유를 기록한다.
