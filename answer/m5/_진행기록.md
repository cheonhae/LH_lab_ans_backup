## 실제로 실행한 확인

```text
$ python scripts/m5_notice_check.py data/m5_sample.csv
게시일 기준(대장): v1 2026-10-05 · v2 2026-10-26 · v3 2026-11-04
전체 15행 · 대조 14행 · 일치 10 · 불일치 4 · 접수일 확인 필요 1
기준 공고별: v1 2 · v2 5 · v3 7
- 5행 S-04 불일치: 기록 v1 → 기준 v2
- 10행 S-09 불일치: 기록 v2 → 기준 v3
- 12행 S-11 접수일 확인 필요: 비표준 접수일 표기 '2026.11.05'
- 13행 S-12 불일치: 기록 v2 → 기준 v3
- 16행 S-15 불일치: 기록 (빈 칸) → 기준 v3
결과 파일: outputs/m5/notice_check.csv
적용 공고 판단은 담당 검토 후 확정합니다.
```

- 머리글만 있는 파일 → "행이 없습니다 — 민원대장 파일에 데이터 행이 있는지 확인하세요." (끝 코드 0)
- `2026-11-31` 한 행 → 처음에는 오류로 멈춤(발견 사항 1) → 고친 뒤 "접수일 확인 필요: 달력에 없는 날짜 '2026-11-31'"
