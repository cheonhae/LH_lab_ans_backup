## 1. 무엇을 하는 도구인가

- 해결하는 업무 불편: 민원대장 적용공고 칸이 접수일과 맞지 않는 행, 답변 기한이 지난 미답변 민원을 주간 보고 전에 손으로 찾는 일
- 주 사용자: 임대공급팀 민원대장 담당자
- 들어 있는 검증 절차: 정합 검사(게시일 기준표 한 곳과 대조) · 계산 검산(답변 기한을 손으로 센 값과 대조)
- 출발점: 조원 ②의 개인 PRD(민원대장 적용공고 확인기)

## 2. 사용법

1. GitHub 웹 **Code → Download ZIP**으로 내려받거나 세션에서 레포를 엽니다.
2. `python scripts/main.py data/team_sample.csv` — 기준일을 바꾸려면 `--as-of 2026-11-20`, 행별 결과 파일이 필요하면 `--out 결과.csv`
3. 요약(불일치 · 기한 지남 · 접수일 확인 필요)과 행 번호·사유가 나옵니다. 판단은 담당 검토 후 확정합니다.
