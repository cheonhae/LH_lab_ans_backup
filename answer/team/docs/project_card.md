# 프로젝트 카드 — 시연용 조(행정)

> 조원이 말하고 드라이버 세션이 채워 커밋(`[팀] 프로젝트 카드`). 실습 0 입력 문장 그대로.

## 1. 주제

- 출발점: 조원 ②의 개인 PRD `prd/m5_my_prd.md`(민원대장 적용공고 확인기)
- 한 줄: 민원대장 담당자가 · 적용공고 칸 오류와 답변 기한이 지난 미답변 건을 손으로 찾는 일을 · 명령 한 줄 확인기로 줄인다
- 넣을 검증 절차: ☐ 근거 대조 ☑ 계산 검산 ☑ 정합 검사

## 2. 범위

| 오늘 만들 것 (MVP) | 오늘 만들지 않을 것 |

| 적용공고 대조(기능 A) | 화면(HTML)·로그인·외부 연동 |
| 답변 기한 확인(기능 B) + 통합 요약 | 답변 문구 작성, 보고서 자동 수정 |
